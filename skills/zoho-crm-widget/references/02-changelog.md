# Zoho CRM Developer Space - APIs, Widgets, Client Script & SlyteUI Documentation

-   v1.5 Latest

    CDN URL: https://live.zwidgets.com/js-sdk/1.5/ZohoEmbededAppSDK.min.js

-   Added

    -   ZRC

        ZRC allows users to make API calls using a widget. Supports CRM APIs, Connection APIs, and External APIs with features like smart suggestions, auto JSON handling, unified syntax, async/await support, robust error handling, and unlimited external API calls.

    -   Multi page support

        Modern web applications built with frameworks like React, Angular, etc. can now run inside CRM Widgets with soft navigation, enabling users to move across pages without reloads.

    -   The following ZDK methods are added to ease usage of Widgets

        [ZDK.Client.showMessage()](https://www.zohocrm.dev/explore/widgets/v1.5/ZDK_Client#showMessage) \- Show a toast message in the page with Markdown support.

        [ZDK.Client.showConfirmation()](https://www.zohocrm.dev/explore/widgets/v1.5/ZDK_Client#showConfirmation) \- Show confirmation pop-ups with custom accept/reject messages.

        [ZDK.Client.showAlert()](https://www.zohocrm.dev/explore/widgets/v1.5/ZDK_Client#showAlert) \- Show alert messages with Markdown support.

        [ZDK.Client.getInput()](https://www.zohocrm.dev/explore/widgets/v1.5/ZDK_Client#getInput) \- Get one or more inputs with customizable fields.

        [ZDK.Client.openPopup()](https://www.zohocrm.dev/explore/widgets/v1.5/ZDK_Client#openPopup) \- Open another widget in a popup window.

        [ZDK.Client.sendResponse()](https://www.zohocrm.dev/explore/widgets/v1.5/ZDK_Client#sendResponse) \- Send response to widget.

        [ZDK.Client.showLoader()](https://www.zohocrm.dev/explore/widgets/v1.5/ZDK_Client#showLoader) \- Show loaders with templates and messages.

        [ZDK.Client.hideLoader()](https://www.zohocrm.dev/explore/widgets/v1.5/ZDK_Client#hideLoader) \- Hides the Loader.
