# Zoho CRM Developer Space - APIs, Widgets, Client Script & SlyteUI Documentation

ZOHO.CRM UI.Popup

-   close ( )

    Close Widget Popup

    Return Promise : Resolved with true | false

    Example

    ZOHO.CRM.UI.Popup.close().then(function(data){ console.log(data) })

-   closeReload ( )

    Close Widget Popup and reload the View

    Return Promise : Resolved with true | false

    Example

    ZOHO.CRM.UI.Popup.closeReload().then(function(data){ console.log(data) })
